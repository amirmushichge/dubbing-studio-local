# Changelog

## 0.1.0-alpha.1 — 2026-08-24

First public alpha of the local Dubbing Studio workflow.

- Added automatic Windows and experimental Apple Silicon setup.
- Added local transcription, translation, multi-speaker voice matching, optional CUDA lip sync, caption editing and quality reporting.
- Added cancellable project queues, safe project deletion, retry recovery and project-isolated exports.
- Added Windows/macOS CI, dependency auditing, secret scanning and pinned-asset availability checks.
- Removed private demonstration media and replaced it with a synthetic mock-mode interface image.

This is an alpha release. Review every result and keep original media outside the repository.
